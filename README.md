# Les temps · les pronoms · les relatifs

프랑스어 문법에서 학습자가 가장 많이 헷갈리는 세 가지, **시제와 법**, **대명사의 순서**, **관계사**를 각각 한 장의 지도로 정리한 사이트입니다.

**접속 주소:** https://hyungwookha.github.io/lestempslespronomslesrelatifs

## 이 사이트는

- **정보 전달용 참고 자료입니다.** 연습 문제나 점수 기능은 없습니다. 지도를 보고, 칸을 눌러 설명을 읽는 것이 전부입니다.
- **한 주제 = 한 장의 그림.** 각 페이지 맨 위에 그 주제를 한눈에 보는 그림이 있고, 그 아래에 누른 칸의 설명, 맨 아래에 규칙 정리가 이어집니다.
- **근거를 밝힙니다.** 설명 옆에 두 문법서의 내용을 색 상자로 붙이고 출처를 적었습니다. 사이트가 직접 쓴 설명과 예문은 따로 구분됩니다.
- **휴대폰에서 읽기 좋게** 만들었습니다. 화면 폭 390px 기준으로 확인했고, 다크 모드를 지원합니다.

## 세 페이지

맨 위의 국기 색 탭 세 칸(파랑 `#000091` · 흰색 · 빨강 `#E1000F`)으로 오갑니다.

| 탭 | 파일 | 맨 위 그림 | 칸을 누르면 |
|---|---|---|---|
| **시제·법** (파랑) | `index.html` | 가로 = 과거 → 미래, 세로 = 법(직설·조건·접속·명령)인 시제 지도. 아래에 부정법·분사 | 만드는 법, 쓰임과 예문, 대명동사 예, 활용표(동사 10개), 시제 일치, PONS·Delatour 상자 |
| **대명사** (흰색) | `pronoms.html` | 목적보어 대명사 순서를 보여 주는 「좁아지는 삼각형」 (*me te se nous vous* → *le la les* → *lui leur* → *y* → *en* + 동사) | 하나를 누르면 무엇을 대신하는지와 예문, 두 개를 누르면 함께 쓸 때의 순서와 쓸 수 있는 조합인지 |
| **관계사** (빨강) | `relatifs.html` | 「뒤 문장에서의 역할 × 선행사(사람 / 동물·사물 / 중성)」 관계사 표 | 3단계 설명(선행사가 다시 나옴 → 빼면 빈자리 → 조각을 끼워 합친 문장)과 그 관계사의 Delatour 상자 |

각 페이지 아래쪽에는 규칙 정리가 있습니다. 시제 일치와 짝꿍 시제, 대명사의 위치·과거분사 일치·강세형, 관계절의 법·일치·강조 구문 같은 것들입니다.

## 상자 색으로 출처 구분

| 상자 | 출처 | 표기 |
|---|---|---|
| 초록 | PONS 문법표 | 상자 머리에 장·단 |
| 붉은색 `#7F2425` | Delatour 『Nouvelle grammaire du français』 | 소제목마다 책에 인쇄된 쪽 번호 |
| 상자 밖 본문·예문 | 이 사이트에서 쓴 설명 | 두 문법서와 대조해 고친 내용 |

두 자료가 서로 다르게 설명하는 곳은 한쪽만 따르지 않고 차이를 적었습니다. 예를 들어 *faire*의 명령형·현재분사를 PONS는 불규칙으로, Delatour는 규칙으로 봅니다. Delatour 안에서도 앞뒤가 어긋나는 예문(시제 일치 p.134와 p.225)은 싣지 않았습니다.

## 화면 기능

- **다크 모드:** 오른쪽 위 버튼. 한 번 고르면 세 페이지를 오가도 유지됩니다. localStorage `french-tenses-theme`에 저장되고, 저장 기능이 막힌 환경을 위해 탭 링크의 `?theme=`와 `window.name`에도 함께 실어 넘깁니다.
- **서버·빌드 없음:** HTML 파일 세 개가 각각 혼자 동작합니다. 글꼴(Gowun Batang, IBM Plex Sans KR, Newsreader)만 Google Fonts에서 불러옵니다.

## 고칠 때 볼 곳

공통: 각 파일 맨 위 `:root` CSS 변수가 색상입니다 (다크 모드 포함, 국기 색 `--fr-bleu` `--fr-blanc` `--fr-rouge`, Delatour 상자 `--dela`). 국기 탭(`.site-nav`)과 다크 모드 코드는 세 파일에 똑같이 들어 있으니, 고칠 때는 세 파일을 함께 고칩니다.

`index.html` (시제·법):

| 이름 | 내용 |
|---|---|
| `T` | 시제별 설명 (만드는 법, 쓰임, 예문) |
| `FORMS`, `AUX` | 활용형 데이터 (`conj()`가 활용형을 만듦) |
| `SOT` | 시제 일치 표 |
| `PONS` | PONS 보충 설명 (초록 상자) |
| `DELA`, `DELA_SOT` | Delatour 보충 설명 (붉은 상자). `delatour-tense-notes.json`에서 만든 데이터 |

`pronoms.html` (대명사):

| 이름 | 내용 |
|---|---|
| `PR` | 대명사별 설명과 예문 |
| `COLS` | 삼각형 칸(①~⑤)에 들어가는 대명사 |
| `PAIR` | 두 칸을 함께 쓸 때의 판정(쓸 수 있음·드묾·못 씀)과 예문 |

`relatifs.html` (관계사):

| 이름 | 내용 |
|---|---|
| `C` | 표의 칸(역할-선행사)마다 관계사, 연결할 Delatour 항목, 3단계 예문 |
| `DELA` | 관계사별 Delatour 설명. `delatour-relatives-notes.json`에서 만든 데이터 |
| `RULES` | 표 아래 규칙 상자 (Delatour·PONS) |

## 작업 방식

이 사이트는 Claude Code와 함께 고칩니다. 작업 규칙은 `CLAUDE.md`에 있습니다.

1. 고칠 내용을 말하면 Claude가 파일을 고치고, **먼저 비공개 미리보기 링크**로 보여 줍니다.
2. 미리보기를 보고 더 고칠 점을 말하면 같은 링크에 다시 반영합니다.
3. **"올려"라고 허락한 뒤에만** GitHub에 올리고 Pull Request를 만듭니다.
4. Pull Request 화면에서 Merge를 누르면 1~2분 뒤 사이트에 반영됩니다.
